# 邀请制赛果投稿

## 首版交互

网站继续公开浏览。投稿页复用 Google 登录，受邀读者可提交赛果或指出现有记录有误。新增赛果填选手、赛事、日期、项目、成绩和 HTTPS 出处。纠错从现有成绩进入，带上记录标识，填修正值和出处。发布内容只包括管理员确认的赛果字段。投稿页和审核页提供日语及简体中文。

## 迁移及影响

- 新建 Atlas 专用的私有投稿队列和邀请表。邀请按管理员预先核对的 Google 身份绑定账号 UUID。数据库使用当前登录身份和有效邀请判断是否有权提交；撤销邀请后立即禁止新投稿。投稿者只能查询自己的状态。
- 队列记录原始建议和审核决定。管理员列表与审核操作在数据库内检查现有 Atlas 管理员权限。待审数据、邀请名单、Google 邮箱、审核备注均不可公开读取。
- 采用现有 `wsd_public_content` 的 `result` 覆盖格式。上线前需确认或单独审阅仓库中尚未启用的受管内容迁移。依赖缺失时，投稿入口不可用。
- 审核发布在同一数据库事务完成。按投稿记录加锁，验证仍待审，新增使用稳定记录键，纠错沿用原记录键。审核员应看到原记录和拟发布值，有并发变更时刷新并重新确认。重复发布不得生成两条记录。只写审核员确认过的赛果字段和出处。
- 共用生产项目。现有网站、旧投稿表及其权限均不在迁移范围。Google OAuth 仅在确有需要时追加 Atlas 回调地址，不覆盖既有回调。

## 上线验证及回滚

先在隔离的测试环境验证匿名、未受邀账号、受邀读者、管理员四种身份。核对未授权读写被拒、读者之间的隔离、撤销邀请立即生效、重复审核的幂等性、纠错可回滚，以及公开页面只读取已经发布的字段。然后确认 Atlas 原有管理员和原网站工作流通过回归检查。

生产实施需要所有者审阅实际 SQL、影响和回滚策略后授权。停用时先关闭入口并撤回投稿和审核 API 的执行权限，保留队列及审核记录。通过现有受管内容审计记录逐条恢复错误纠正前的覆盖值；没有旧覆盖的纠错须撤除新覆盖，使静态原记录重新显示。新增赛果可软删除。备份并验证恢复后再考虑移除新增对象。
